Sécurité de Bonk

Bonk écrit sur des disques entiers : une faille peut détruire des données. Signalez les vulnérabilités en privé, jamais dans une issue publique.

Signaler

  • Signalement privé GitHub : seul le mainteneur le voit.
  • security@bonk-os.app : chiffrez tout détail exploitable avec la clé ci-dessous.

Clé OpenPGP

IdentitéBonk Security <security@bonk-os.app>
EmpreinteA782 AC57 321A 862C 2ED8 F0FB 34F1 5332 E2A0 7A30
Expiration2028-10-30

Récupérez la clé par au moins deux canaux et comparez l'empreinte :

  • ce site
  • le site principal
  • le dépôt de Bonk
  • DNS : TXT openpgp4fpr sur bonk-os.app, et un enregistrement OPENPGPKEY
  • Web Key Directory : gpg --locate-keys security@bonk-os.app

Ce que vous pouvez attendre

Accusé de réception sous 7 jours, première évaluation sous 30 jours, divulgation coordonnée avec le correctif, au plus tard 90 jours après le signalement sauf accord contraire. Ce sont des objectifs, pas des engagements contractuels : le projet n'a qu'un mainteneur.

Politique

Périmètre, recherche de bonne foi et historique des clés : politique complète. Lisible par machine : security.txt.
